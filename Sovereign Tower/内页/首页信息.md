# 3、网站主题色

### 结论：**默认使用亮色主题。**

Sovereign Tower 的美术很明显更适合 **羊皮纸/米色背景 + 酒红 + Dusty Rose 尘玫瑰色**，而不是 Roblox Wiki 常见的黑底霓虹色。

首页默认亮色会更像游戏本体那种手绘中世纪故事书 / Visual Novel UI，同时长篇 Knight、Quest、Romance、Choice Guide 的阅读体验也更舒服。

我建议主色用 **Muted Burgundy 酒红色 `#8F4B57`**，辅助色用 **Dusty Rose `#C77D8A`**：

```css
/* 导航页主题色 - 亮色主题 */
--nav-theme: 349 31% 43%;        /* muted burgundy #8F4B57 */
--nav-theme-light: 349 40% 64%;  /* dusty rose #C77D8A */

/* 导航页主题色 - 暗色主题 */
--nav-theme: 349 40% 64%;        /* dusty rose #C77D8A */
--nav-theme-light: 352 61% 77%;  /* soft rose #E8A0A9 */
```

我的整体视觉建议是：

**默认 Light → 羊皮纸米白背景 + 酒红导航/按钮 + 灰粉强调色。**

Dark Mode 再做成 **深棕紫背景 + Dusty Rose 高亮**。这样不是单纯「换成黑色」，而是两套主题都保持 Sovereign Tower 的味道。

# 4、多语言

## 结论

如果你**最多只做 4 门、排除中文、必须包含英语**，我建议：

**① English → ② Japanese → ③ Korean → ④ French**

Steam 官方目前只提供 **English、French、German、Japanese、Korean、Simplified Chinese** 这 6 种界面/字幕语言，所以你的多语言站最好严格围绕官方真正支持的语言做，不建议一上来自己扩 Spanish、Portuguese。([Steam 商店][1])

需要说明一点：官方并没有公布「玩家按语言拆分的流量数据」，因此下面是根据 **官方本地化覆盖、当前搜索内容活跃度、地区玩家习惯和游戏类型** 得出的 SEO 优先级，而不是官方用户占比。

| 优先级   | 语言            | 推荐本地化主题名                       | URL 建议       | 原因                                                   |
| ----- | ------------- | ------------------------------ | ------------ | ---------------------------------------------------- |
| **1** | 🇺🇸 English  | **Sovereign Tower**            | `/` 或 `/en/` | 主发行语言、官方 Discord 语言也是 English，核心 SEO 流量必须先吃          |
| **2** | 🇯🇵 Japanese | **ソブリン・タワー / Sovereign Tower** | `/ja/`       | 日语已官方完整本地化，这类角色、恋爱、分支剧情、Visual Novel RPG 与日本攻略搜索非常匹配 |
| **3** | 🇰🇷 Korean   | **소버린 타워 / Sovereign Tower**   | `/ko/`       | 韩国已有明显的本地化内容和游戏视频需求，攻略型搜索与角色信息页面潜力不错                 |
| **4** | 🇫🇷 French   | **Sovereign Tower**            | `/fr/`       | 开发商 WILD WITS 本身就是法国 Rennes 工作室，游戏有完整法语本地化和法国本地宣传基础  |

Steam 的日文、韩文和法文官方商店页面目前都仍以 **Sovereign Tower** 作为正式游戏名，并没有像简中那样正式把商店标题改成另一个名字。([Steam 商店][5])

所以这里有个很重要的 SEO 处理：

**不要把日文页面的 `<title>` 只写成「ソブリン・タワー Wiki」。**

更建议：

```text
ソブリン・タワー (Sovereign Tower) Wiki
```

韩语同理：

```text
소버린 타워 (Sovereign Tower) Wiki
```

这样可以同时覆盖当地玩家的音译搜索和 Steam 官方英文游戏名搜索。

**German 我会暂时排第 5。** Steam 确实完整支持德语，但从这个游戏目前的公开内容与搜索生态来看，我会优先把有限精力投给 English / Japanese / Korean / French，等这四版真正有 Google Impression 后，再决定要不要扩 `/de/`。([Steam 商店][6])

另外，这个游戏现在才刚发售几天，**非常适合尽快铺 Knights、Quest Matching、Romance、Choices、Time Rewind、Endings 这类长尾页**，比继续做一个大而空的首页更重要。当前 Steam 已经有 1,000+ 评价，说明搜索需求正在快速形成。([Steam 商店][1])
