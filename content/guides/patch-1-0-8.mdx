## Direct answer: what changed in Patch 1.0.8?

Patch 1.0.8 is an official Sovereign Tower update published in the Steam Community announcements on August 10, 2026. It fixes several bugs, adds save/load confirmation, changes quest balance and adjusts the Dragon Knight encounters. It also reduces Forge repair costs and gives the emergency Grest pirate quest one additional cycle on its deadline.

This page records the official note rather than guessing how large each balance change is. The announcement does not publish a new universal quest formula or a complete table of every changed value. Treat older Demo thresholds, repair prices and route advice as historical until they are tested against the current build.

## Bug fixes

The patch adds a workaround for a crash at the Godot loading screen when Steam initialization was not verified correctly. It fixes an issue that made Gwendan immortal and a repeated event in which Gwendolen mourned Gwendan's death twice. It also fixes a Ligia questline problem that could lock the player into the same item-finding choice.

The official notes also remove an exploit that allowed purchases without the necessary gold when using the Blacksmith through the Round Table room. A rogue spellbook appearing after recruiting the Pawnbroker is fixed as well. The update includes multiple typo and string-display fixes across the supported languages.

## Quality-of-life changes

Patch 1.0.8 adds a confirmation pop-up before saving or loading. This is a small interface change, but it matters in a branching game because it makes accidental timeline changes less likely. If a guide discusses save management, it should identify whether the advice was written before or after this patch.

The patch also buffs multiple items available in Acts 2 and 3 to help with the increased difficulty in later quests. The announcement does not list every item or publish a new item table. A guide can safely mention the direction of the change, but should not invent the exact bonus for an item that is not documented in the official note.

## Quest and Forge balance

The difficulty of quests against the Dragon Knight was adjusted. The penalty applied when a Knight is weak against a required stat was reduced, while the score bonus for being over-levelled in a required stat was increased. These changes mean that a pre-1.0.8 threshold or score interpretation may not describe the current result accurately.

The initial and subsequent costs of Forge repairs were reduced. The official announcement does not provide the replacement prices, so this page intentionally does not turn the change into a fabricated cost table. Check the current in-game value before publishing a numerical Forge guide.

## Grest emergency quest

The emergency quest in Grest against the pirates has its deadline timer increased by one cycle. The official note confirms the direction of the change, but it does not state a universal best Knight assignment or every consequence of delaying the quest. Use the extra time as a current-build allowance, not as proof that every route is now safe.

## How this affects existing guides

The most important practical rule is to put the build next to every exact quest threshold, score claim and price. A route that worked in the Demo can still explain the story context, but it should not be labelled as a guaranteed release answer without a current test. The same applies to community spreadsheets and file-derived tables.

For this site, Patch 1.0.8 is the current evidence boundary. Official system descriptions can remain stable, while exact scoring, Forge prices, Dragon Knight difficulty and emergency deadlines should be reviewed again when a later patch appears. If two public guides disagree, preserve the disagreement until the game or an official note resolves it.
